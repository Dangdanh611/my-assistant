Cách nhúng vào website
Chỉ cần 1 dòng script

Thêm đoạn code sau vào cuối thẻ <body> của website:

<!-- Floating Web Assistant --> <script src="https://yourdomain.github.io/floating-assistant.js" data-config="https://yourdomain.github.io/config.json" ></script>
Deploy lên GitHub Pages
  1. Upload floating-assistant.js lên repo
  2. Upload config.json lên repo
  3. Bật GitHub Pages trong Settings
  4. Nhúng script vào website của bạn
